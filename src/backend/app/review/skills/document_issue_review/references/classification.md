# 疑点分类与证据矩阵

| 类别 | 输入证据 | 风险 | 推荐处理 |
|---|---|---|---|
| 扫描缺页/无可核验文本 | 已知源页数与解析覆盖/页图 | 确切遗漏红；页数未知无法判断 | 重传完整原件，范围确认后重识别 |
| 模糊、反光、裁边、低清晰 | 解析质量标志及对应页/区域 | 无法判断；视觉候选黄色 | 补拍对应页或裁切区域，核对后采用 |
| 单号/收发人/地址等未提取 | 类型字段清单和现有候选 | 无法判断，不声称源文不存在 | 对照原图补充识别；明确原件空缺时补材料 |
| 字段/跨单据事实冲突 | 同角色、同口径、有源的明确比较 | 确定错误红；映射/单位前提不全无法判断 | 用户核验来源、确认适用范围，不能凭译文修订解除 |
| 角色/语义/术语错译 | 源译对应段、业务语境 | 模型候选黄色 | 手改/Agent意见/完整单段推荐替换 |
| 漏译/空译/保护数字单位变化 | 源译映射与保护值 | 确定缺段空段或保护值丢失红；语义漏译候选黄 | 修改对应译段、重算本段QA预览 |
| 表格/分页/布局对应异常 | 解析结构、映射、页/行/单元格 | 明确交付内容丢失红；视觉疑似黄/无法判断 | 重新识别/手工核验对应段；不扩大范围猜修 |
| 税号/HS/许可证/特殊货物专业条件 | 类型资料和已审规则适用输入 | 专业证据未覆盖/无法判断 | 有资质人员审核，不能冒充自动法规判定 |

同一问题一次处置不得清除同段独立疑点。旧检查和原件不覆写；新版本保留未改变问题和历史处置。已解决项不再出现在待处理字段/疑点列表，历史可从处理记录查看。
