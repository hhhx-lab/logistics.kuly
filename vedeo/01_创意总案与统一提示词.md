# 《一张单据的旅程》｜28 秒首页宣传片创意总案

> 用途：物流单证智能体首页首屏的无声自动播放视频，也可配旁白用于宣发。此文件定义所有镜头共同遵守的故事、视觉和生成约束；可独立复制的逐镜提示词见[02_28秒分镜与逐镜提示词](02_28秒分镜与逐镜提示词.md)，剪辑与页面适配见[03_剪辑合成与首页交付规范](03_剪辑合成与首页交付规范.md)，参考帧与界面合成指令见[04_角色道具参考帧与界面合成提示词](04_角色道具参考帧与界面合成提示词.md)。此处只交付脚本和提示词，不代表已生成视频。

## 1. 一句话创意

一份从德国汉堡发往中国的商业发票，随着一票货物经过发货人、货运协调员、口岸单证审核岗和收货人；四个人在交接节点用同一个单证智能体看懂、翻译、核对与确认，纸张在镜头间接力，信息始终有来源。

**片名**：《一张单据的旅程》  
**长度**：28 秒，7 个主镜头 × 4 秒。  
**风格**：写实真人商业短片；清晨自然光、干净的工作环境、克制的海蓝与纸白；有人的动作和温度，没有科幻全息屏。  
**观感目标**：第一遍静音播放也能看懂“同一票货、不同岗位、同一个助手”；有声版补足情绪与故事。

### 观众在 28 秒内必须看明白的三件事

1. 对话发起处理：上传单据、说清目标语言和核对要求。
2. 智能体辅助识别、翻译和展示疑点；关键内容由人复核，原件与译文可对照。
3. 同一单票的资料在运输与交付节点可再次查阅；最终通关和签收仍由相应人员按实际流程完成。

视频演示的是**虚构样票与模拟业务场景**。口岸镜头不展示真实海关标识、不假借官方身份或合作关系；“通关”由实际业务环节完成，片子不声称助手自动放行、保证通关、代替海关决定或签发原始单据。

## 2. 故事和物件连续性

| 固定元素 | 所有镜头一致的设定 | 在剪辑中的作用 |
| --- | --- | --- |
| 主角单据 | 一页 A4 商业发票样稿，白色微暖纸；左上一个浅蓝色直角折角，右上虚构编号 `DEMO-INV-1008`；装入透明文件夹后仍能看到折角 | 不靠 AI 生成的小字辨认身份，而靠折角、纸色和透明夹保持连续。编号用后期贴图，不让模型生成正文。 |
| 同票资料 | 文件夹后面隐约有装箱单和运输资料，始终虚构且不可读 | 表示单票不只有一张发票；不暗示一张发票足以完成全部通关手续。 |
| 货物 | 20 箱可重复使用的蓝色收纳箱，外箱为未印品牌的牛皮纸箱 | 运输画面与单证场景对应；准确数量仅在后期可控的产品 UI 中出现。 |
| 路线 | 德国汉堡工作室与港区 → 海上航线 → 中国上海口岸 → 江苏苏州收货仓 | 视觉方向始终由画面左向右；地图文字和路线线条均后期合成。 |
| 数字副本 | 同一虚构业务资料的授权副本；各岗位只在各自有权的工作空间上传或查看对应材料 | 不把真实纸张在海上“魔法瞬移”，也不暗示跨企业账户会自动共享单票记忆。 |
| 产品 UI | 实际项目页面的简化录屏/设计合成：对话、原译对照、疑点、复核、来源 | 不让视频模型凭空画界面、字段、印章或译文。文字、按钮、红黄高亮均在后期可控图层制作。 |

**四位虚构成年角色**（都不指向现实人物）：

- **发货人 Elena**：约 30 岁，短棕发，米白衬衫；在汉堡工作的中英双语出口单证员。动作克制、熟练。镜头 1–2 使用同一角色形象与服装，使用中文产品界面合理。
- **货运协调员 Lin**：约 35 岁，深蓝工作马甲；港区内侧的明亮单证办公室。镜头 3 出现。
- **口岸单证审核岗 Mei**：约 40 岁，浅蓝衬衫，普通工牌但不带国家机关徽记；演员演绎中国口岸海关单证核验情景，地点为上海口岸协作办公室。镜头 5 出现。她查看译本和原件，在独立审核记录上签名确认核对；画面不暗示真实海关已采用本产品。
- **收货人 Zhou**：约 30 岁，灰绿色工装外套；苏州仓库签收台。镜头 7 出现。查看单票摘要后，在独立纸质签收单上签名。

每段生成尽量只出现一个清晰人物；室内交接通过同一张发票从画面右侧出去、下一处桌面从左侧进入完成。镜头 4、6 分别只拍货轮和货车，利用前后纸张镜头让观众理解文件随业务流转，避免生成器画出悬浮纸张或反复改变角色面部。

## 3. 统一视觉与镜头语言

**摄影**：真人实拍质感，16:9，镜头高度接近人的视线；工作台用 50 mm，单据与手部用 85 mm，物流环境用 35 mm。浅景深只用于人物情绪和纸张折角，任何需要辨认产品信息的画面通过后期 UI 合成，保持清晰。所有推拉、平移都缓慢，拒绝急变焦、甩镜和过度慢动作。

**光色**：海外晨光偏暖奶油色，海上清透蓝色，口岸日光偏冷但不阴沉，收货仓午后略暖。固定锚色为纸白 `#F6F4ED`、深海蓝 `#1D4867`、柔和青 `#7BA7A5`、浅沙色 `#D9C8AA`；整体对比度中等、肤色自然、细微胶片颗粒。

**关键转场**：

1. 镜头 1→2：Elena 伸手触碰屏幕右下角；切到她手指确认修订的近景。动作连续。
2. 镜头 2→3：发票折角从画面右缘离开；下一镜同一折角从左缘进入 Lin 的桌面。物理交接不必露出第二张脸。
3. 镜头 3→4：Lin 将透明夹放向画面右方；透明夹边缘擦镜，变为货舱边缘与海面。
4. 镜头 4→5：船身右行；切到上海口岸文件夹从左侧放上桌，方向和颜色保持。
5. 镜头 5→6：Mei 合上透明夹，手离画右；下一镜货车向右行进。通关环节用真实场景作独立过渡，不要求在远景看见小小的文件袋。
6. 镜头 6→7：车门／文件袋从右离画；下一镜同样文件夹从左到达 Zhou 的签收台。

转场主要用动作匹配与直切。允许 2–4 帧纸边擦镜；不要用巨大漂浮纸张盖住港口或科幻粒子。镜头两端各保留 8–12 帧动作余量，避免裁切时动作断裂。

## 4. 统一母提示词

以下母提示词用于锁定整体风格和准备多镜头项目；[02 文件](02_28秒分镜与逐镜提示词.md)中的每段镜头提示词已经完整包含其所需设定，可单独复制，不必再次拼接母提示词。若某平台支持项目级风格设定，把母提示词放在项目级，把逐镜词放在镜头级即可。**分镜按独立 4 秒镜头生成，再剪成 28 秒**；不要把 28 秒写在提示词里指望单次生成自动满足。若使用 Sora 等按参数计时的平台，时长与分辨率必须通过生成参数设置，提示词本身不能替代参数。

### 生成前锁定的具体变量

| 变量 | 固定值 | 为什么必须固定 |
| --- | --- | --- |
| 光线方向 | 汉堡两镜从画面左上窗户入光；Lin 镜左侧冷日光、右后暖灯；上海右上窗光；苏州左后午后暖光 | 若同空间内光向反跳，会看出素材不是同一时空。 |
| A4 单据 | 长边朝人物，直立时竖版；厚度为普通复印纸；浅蓝折角在纸张物理左上角，折起约 18 mm；透明夹只一层 | 避免纸张变成海报、折角换侧或重复套袋。 |
| 屏幕占位 | 笔记本／平板屏幕为均匀浅灰蓝低反光，不出现任何可读字；屏幕四角清楚、被手遮挡区域真实 | 后期才能把项目真实 UI 跟踪进去，避免 AI 假字与手指错位。 |
| 人物动作 | 视线先看纸／屏，再做一个明确操作；无对镜头说话或夸张胜利手势 | 真人工作状态比“演示软件”姿态自然。 |
| 画面方向 | 道具或车船整体从左进入、向右离开；特写中的纸张也顺此方向 | 七段素材才可用动作匹配剪成连续旅程。 |
| 音画分工 | 生成镜头不承担台词、中文字幕、品牌标识；音效、旁白、字幕、UI 后期独立制作 | 防止不可编辑的乱码和唇形错误。 |

每镜画面先预留中心 70% 的主要人物／单据，再为字幕留一块真实背景中的低细节区域；画面顶底各 10% 不放只能在那里才能看到的重要动作，便于首页小屏适配。不要为了单一精确坐标让人物姿态僵硬；实际安全区在选定素材后复核。

## 5. 叙事文字与旁白

静音观看时，后期标题按以下节奏出现，每条只保留约 1.5–2 秒，禁用模型直接生成中文：

| 时间 | 后期字幕 | 画面传达 |
| --- | --- | --- |
| 0–4 秒 | `一张单据，从这里出发。` | 发货人上传样稿。 |
| 4–8 秒 | `识别疑点，人工确认。` | 对照与修订。 |
| 8–12 秒 | `交接的人，读懂同一票。` | 货运协调员查询摘要和来源。 |
| 12–16 秒 | `跨越语言，也跨越海洋。` | 船与航线。 |
| 16–20 秒 | `原文、译文、疑点，逐项可查。` | 口岸单证复核。 |
| 20–24 秒 | `流程向前，记录可追。` | 货物按正常通关流程继续。 |
| 24–28 秒 | `让每次交接，都有据可查。` | 收货签收、产品名和按钮。 |

**有声版旁白**（温和、可靠的成年女性或男性普通话，分四句落在镜头 01／03／05／07；留出环境声与结尾呼吸）：

> 一张单据，从发货人的桌前出发。识别、翻译、核对，让交接更明白。抵达口岸，人工复核有据可查。收货时，来龙去脉也看得清楚。

首版优先用专业配音与低音量原创/已授权音乐；各人物不说台词，减少口型与跨镜头语言匹配问题。结尾屏幕产品名统一用当前项目的正式名称，按钮文案建议 `体验单据翻译与校验`，Logo 由已有品牌资源后期加入。

## 6. 产品事实边界

- 发货人镜头表现的是**上传已有样稿、发现疑点、人工修订和确认**，不表现产品从零自动签发商业发票。
- 运输、口岸、收货三次查询都围绕同一虚构业务的原件与授权副本；各自通过所属组织已授权的资料和账户工作。不得暗示任何角色能绕过身份权限读到另一企业的 Case、处理记录或真实资料。
- 红色疑点表示待解决的重要问题，画面必须有人工处理动作；不把黄色提醒说成硬阻断，也不显示假造的“全部合规通过”。
- 口岸人员演示单证翻译和审阅；放行镜头作为独立正常流程，不写“AI 自动清关”。
- 签收笔迹落在独立收货单上，不伪装成应用内电子签章或原始运输单据签发。
