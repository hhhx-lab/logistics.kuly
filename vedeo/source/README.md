# 《一张单据的旅程》逐帧动画源码（体素方块风）

用 Python 代码逐帧渲染的宣传片动画，全片 9 个镜头、45.5 秒、无声。
主线：一张商业发票从汉堡发货方出发，随货船出海，经船方、上海口岸单证核验、铁路陆运，最终到苏州收货人手中；每一站都是“人看智能体给出的结果，再由人确认、交接”。
画面中的贴图、图标、界面全部由代码原创绘制，没有使用任何第三方游戏的贴图、模型、字体或标识。

## 文件

| 文件 | 作用 |
| --- | --- |
| `voxel.py` | 小型软件渲染器：透视相机、深度缓冲、像素贴图、太阳光与阴影、半透明混合、雾 |
| `scene.py` | 镜 01–02 的场景与角色：办公室、窗外港口、Elena、单据、透明文件夹 |
| `chars.py` | 通用方块角色（Lin / Mei / Chen / Zhou）、飘动的单据、平板、笔 |
| `sets.py` | 镜 03–09 的场景：汉堡外立面、海面与货船、船甲板、口岸办公室、铁路货场与列车、江南水乡、苏州收货仓库 |
| `common.py` | 字幕与镜 01–02 产品界面的矢量绘制，颜色与缓动工具 |
| `ui2.py` | 镜 03–09 的平板界面、放大面板、底部交接链、地点标签 |
| `hud.py` | 方块游戏语汇的叠加层：流程物品栏、字段标签、扫描光、疑点定位框 |
| `shots.py` / `shots2.py` | 镜 01–02 / 镜 03–09 的机位、动作时间线与合成；可单独渲染某一帧 |
| `render.py` | 按镜头时长批量渲染全部帧并调用 ffmpeg 编码为 MP4 |

## 运行

```bash
conda env create -f environment.yml
conda activate doc-journey-anim
cp .env.example .env                       # 可选：改字体、质量、并行数

python shots.py 2 1.5 1                    # 单帧预览：镜 02、镜内第 1.5 秒、超采样 1
python shots2.py 8 0.5,2.2 1               # 单帧预览：镜 08 的两个时刻
python render.py --frames ./frames --keep --out ../deliver/document-journey_home_45s_16x9_v01.mp4
```

输出规格：1920×1080、24 fps、H.264、yuv420p、faststart、无音轨，共 1092 帧。
超采样为 2 时单帧约 3–15 秒（铁路、江南镜头最慢），单进程峰值约 2 GB 内存。
渲染中断后用同样的 `--frames` 目录重新运行即可，已渲染的帧会自动跳过。

## 画面内容与事实边界

- 每一站都是人在操作：智能体只给出识别、翻译、疑点提示和查询结果，确认、复核、签收都由人完成。
- 疑点只有在人点击之后才显示“已人工确认”；签字只签在独立的纸质签收单上，不签在平板上。
- 不表现自动通关、自动放行；不出现海关徽章、官方印章、制服标识或真实公司品牌。
- 全片使用虚构样票 `DEMO-INV-1008`，场景标注“情景演示”或“示意”。
- 片尾按钮“体验单据翻译与校验”只出现在片尾卡，片中不画任何未上线的界面操作。
