# 汇演示例包制作与验证说明

## 制作目标

制作两组可独立上传的同票多单证材料，覆盖法语、英语、中文及西班牙语、英语、中文的两条演示线路。每组用3份核心单证演示；另外提供中文采购单用于三语扩展，每组不超过5个上传文件。正式交付保留可编辑DOCX和对应PDF，另提供真实栅格扫描版供MinerU验证。

## 单票设计

1. 法国设备海运：同一货批3个SKU、120件、12个木箱，商业发票、装箱单与提单一致。明确区分货物数量与外包装件数；箱单附包装分配表，不能将它与商品汇总表重复相加。展示多页、重复表头、合并单元格、金额、主体角色和运输路线。
2. 西班牙食品冷链：同一货批2个SKU，发票与提单600箱，初版装箱单590箱；同一草莓批次存在10箱差异及配套重量差异，邮箱有独立拼写疑点。提供正确补件版，但须与初版分开上传并明确替换关系，不能将两版作为独立新货物累加。
3. 每组另提供中文采购单。采购单是商业交易证据，不等同海关签发文件；涉及未知规则或类型时允许通用处理及无法判断。所有企业、联系人、订单、箱号和单证编号均为演示合成，不包含真实私人或商业资料。

## 来源与样例

从官方或承运人公开页面找空白单证模板，保存原始PDF、来源URL、下载时间和SHA256。公开文件与两组自制货批不混票。将公开模板页转换成图片用于OCR展示，保持版式与归属，不填造官方签字或盖章。

## 验证标准

- 所有DOCX通过本机文档检查，所有PDF通过本机PDF检查。
- 核对页数、表格数、可抽取文本、中文／法语／西班牙语字形、横线、分页、总额与数量真值。
- 每页渲染复核；图片型扫描PDF必须没有可复制正文且有完整页图，原生PDF必须可抽取正文。
- 记录各文件哈希和页数、各货物行数量及计量口径、预置差异和推荐汇演流程。
- 文档级验证不等同实际Agent已通过；未执行真实模型／MinerU作业，不记录为业务验收成功。
