# 翻译校验测试单据与操作说明

这是一份合成英文商业发票，无真实客户信息。推荐首次上传[DOCX原件](assets/翻译校验测试_商业发票.docx)；也可单独上传[PDF原件](assets/翻译校验测试_商业发票.pdf)测试PDF来源定位。两者是同一份材料，不需要同时上传。[Markdown源稿](assets/翻译校验测试_商业发票.md)便于修改后重新生成。

## 操作

1. 打开新对话，点击单据转换卡片并上传DOCX。
2. 输入：“把这份商业发票翻译成中文并校验，保持编号、金额、币种、数量和单位不变，输出PDF和DOCX。”
3. 检查任务草稿，确认目标语言、文件、输出格式后启动。
4. 查看真实进度；若外部服务排队或超时，以任务记录为准，不重复创建同一任务。
5. 在校验侧栏检查原文/译文、关键信息、疑点和来源定位。
6. 修订净重候选为420.00KG（本合成样本指定的人工采用值），执行局部重算；如果电话占位格式被标疑点，可核对测试声明后按页面支持的人工处理流程处理。
7. 完成复核确认与导出，检查管理台是否保存原件和成功导出快照。
