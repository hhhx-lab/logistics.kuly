# 隐私与数据处理说明

更新日期：2026-10-08。本文说明本项目的处理范围和边界，外部服务的具体区域、保存时间及删除能力须以部署者已核实的政策为准，不代表供应商承诺。

## 数据如何处理

- 上传原件存放在项目配置的对象存储；文件元数据、解析与来源定位、业务字段、任务状态、人工处置和成功导出记录存入业务数据库。
- 可本地解析的PDF/DOCX优先按实际解析选路处理；扫描件等需要OCR的材料可发送给MinerU服务。需二次识别的局部图像可发送给部署配置的多模态模型。
- 字段抽取、翻译、译文检查与疑点修订使用部署配置的模型服务；请求按任务发送相应文本、字段或局部来源。外层对话模型接收系统策略、本人确认的偏好、当前会话上下文及本轮授权的单票材料，模型服务采用OpenAI兼容协议，实际提供者由部署配置决定。
- OCR、模型、存储服务的启用情况、实际数据范围及已核实的区域/留存/删除信息由`GET /api/v1/data-processing-disclosure`返回。启用角色应与实际配置保持一致；政策未知时不得写成已核实或保证不留存。
- 首版MCP仅允许配置批准的公开只读范围，不支持将敏感单票内容发送至用户自建外部工具。

## 留存与删除

单票留存到最后一次实质业务变更后的第30个24小时，以服务端期限为准；查看、搜索、提问、下载、后台进度和失败重试不延长期限；本人主动申请删除该票后立即停止内容访问，并清理其原件全部版本、解析、索引、译文、预览、交付与相关单票记录。后台清理期间仅保留不含票据正文的最小删除回执。主存清理目标为24小时内，加密备份按既定最长7天轮换和删除账本重放策略处理；部署验收须核实这些运维措施。已下载或向外发送的副本无法由本系统远程收回，第三方副本按其实际政策处理。

用户记忆按本人身份隔离，只有用户确认的偏好保存为长期记忆。新对话不装配过往聊天或其摘要；当前会话最多使用近20轮及仅属于该会话的压缩摘要。单票、原件、任务和快照仅在当次上传或显式关联且通过权限检查后加载。

## 上传及部署约束

上传弹窗只提供选文件、归票、上传、结果和失败重试，不再显示处理节点、合成材料提示或额外告知确认。点击“开始上传”时读取当前政策版本，既有`disclosure_version_ack`字段用于配置版本核对与政策快照留档，不能当成用户逐项确认记录。

取消额外确认不改变部署材料模式和上传可用性：合成验收部署只用于不含真实个人或商业信息的合成材料；真实材料部署须先核实启用服务的区域、留存和主动删除依据。未满足部署条件时接口仍拒绝上传，页面显示实际不可用原因。服务配置变化后需更新本文及非秘密政策配置。

接口密钥和令牌仅通过部署环境文件管理，不进入页面、模型上下文、普通日志或提交内容。日志不记录大段原文；文件读取、引用、检索、下载及事件流均需验证当前身份和数据权限。
