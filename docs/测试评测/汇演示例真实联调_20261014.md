### F01：页眉与表格标签误切逻辑单据（已修复并真实验证分组）

- 最小修复：表格/嵌图标签不充当独立单据标题；仅明确header或同页顶部、短且符合编号/文档集元数据模式的前置片段并入首标题；真实未知封面/正文仍保持独立。逻辑名称取真实标题，所有原段与anchor原样保留。

- 回归范围：原生PDF页眉+多页续标题+表格标签不误切；真实未知前文不吞并；原有边界/解析测试及前端类型检查。

### F02：抽取字段头与多语计量别名不足（已修复，完整矩阵待验）

- 原生箱单的`Line / SKU / Lot / Quantity / Unit / Packages / Package type / Net kg / Gross kg`未被标为表头，因为现有词典漏了部分常见列名，所有列必须匹配的判定因而失败。原件SNS-T8明确可读，但首轮提单对应候选遗漏SKU；箱单第三行还需完整轮次核验。

- 同一解析经新Run重抽取会留有旧的漏列候选；比较投影按可证明的同一物理表格行归并一致候选，采用字段更完整的行并冻结旧ID到新ID的映射，不删除旧LineItem。数值有矛盾时不按同值或同SKU强行合并，异表/异页/异行保持独立。
