- 幂等入口先取事务 advisory lock，避免并发创建尚不存在的幂等记录出现唯一索引 500；同草稿不同键仍由草稿锁及数据库唯一约束拒绝第二 Run。
- 缺目标语言不创建 Run；范围统一 `all/goods_description/selected_sections`，只读范围 `selected_documents/case`。货描选择器固定 `cargo_description@1`，规则包固定 `core-document@1`；不存在的规则／术语版本拒绝冻结。
- 草稿和 Run 响应补充冻结源版本的真实文件名、字节数、上传人及时间，TaskSpec 仍只保留稳定 ID／版本。
- 取消增加执行栅栏，不抹去已发送外部请求账本；失败重试只能从 `failed_retryable` 进入新 Epoch。存在 `submitting/needs_reconcile` 步骤时拒绝普通重投；导出重试由 R15 独立执行。
- 人工回答核对活动请求、解析版、业务版（包含仍为空）、候选及来源。首分类无业务版时保存回答供恢复抽取建立基线；已有业务版的分类／语言决定写覆盖版。取消／重试／回答同事务更新续答状态。
