更新日期：2026-10-02。依据：后端开发方案 Agent 与提示词、前后端接口与状态契约。范围：C01–C09 会话接口、异步对话图、固定引用证据答复与只读问答续答；工作流命令、引用冻结、迁移由对应模块提供。

## 输入、执行和输出

- C01–C07 接受登录主体、幂等键、结构化引用与能力标签及已验收上传文件。C04 在 Case→Conversation 锁下校验旧键、有效回合租约、单票归属和 TaskDraft，保存 ReferenceSnapshot、用户消息、Prompt 版本/哈希、非秘密模型绑定和 Turn；同键异参返回冲突，另一有效回合返回 TURN_BUSY。正文中的 `/` 和 `@` 不触发扩展调用。
- C04同事务登记topic=turn的QueueOutbox，Celery document_agent.turn消费者经受限worker_tenant_of_turn只查租户后重验身份、按Case→Conversation→Turn领取租约。ConversationWorkItem保存请求、意图、工具结果、答复草稿与模型记录；LangGraph仅存短ID，新轮清空临时状态。PostgreSQL checkpointer持久化，每30秒续租，已提交工具/意图复用；外部模型受理状态未知不盲重投。
- 快路径处理进度、明确字段、翻译目标语言、复核入口和已注册内置能力。含糊意图通过冻结的 OpenAI 协议 CHAT 绑定及 Prompt Registry 生成结构化候选，仍受动作/标签白名单和计划次数限制。模型配置缺失或不可用时真实澄清，不回假生成结果。
- 字段和片段读取仅使用本轮冻结 ParseArtifact；核验租户、Case、原件版本、逻辑单据、区段和 SourceSegment。数字/裁定/位置不依赖模型自由改写，首版采用确定性来源格式；未知证据或跨票证据输出无法确认，冲突各方保留。合成解析产物不用于正式证据答复。
- 最终消息、已验证段落、来源卡、message_final 与 Turn completed 同事务提交。SSE 使用持久事件表，原始模型 token 不透传。消息分页和事件补齐保留独立序号。
- 超过直接窗口或输入预算时，真实CHAT绑定以冻结的chat.session_summary@1对同会话最多20个完整旧轮做增量摘要；保留自由用户要求/术语为待核低信任内容，助手正文/卡片字段不送模型，仅送受控主题与对象ID。不可用时保留deterministic_requirements@5保守后备；语义摘要优先读取，完整性按实际未覆盖的已完成轮次判断。摘要受.env token预算限制，不作本票字段结论或已确认TaskSpec；新会话无其他会话消息/摘要。C06只暴露预算与来源概况。
- 文件未解析时，在 Case→Run 锁下准备/启动或精确复用 read_index、登记 AssistantContinuation、首轮说明、完成事件和 Outbox，同事务释放回合锁。Worker 在自己的状态事务内调用 enqueue_run_continuations，retryable/reconcile 保留原问题，恢复 waiting，indexed 投递独立续答，终止发无事实结果。
- answer_continuation 使用独立只读服务，只读原问题、源版和本 Run indexed RunEvent 中的 parse_artifact_ids，不读取后来消息或复用会话图线程。消费者重新核验授权、会话状态和来源，按产物指纹去重；会话结束不追加事实消息，撤权停止答复。
- C08候选覆盖授权Case、Run、原件、固定区段和成功快照，日期/角色/主体/语种/格式/风险等复用management.query_runs与SQLSearchProjection筛选；跨票显示不可加入。历史Run候选指向成功快照，原件携固定parse。发送时冻结snapshot真实manifest并限制字段ID，Run使用自身发布parse集合，不取同票其他Run最新parse。C09已接D6真实Skill/MCP及实时版本授权验证。
- 简单单证术语使用发布说明；复杂无原件物流知识问题走chat.general@2（旧版仍保留）及GeneralKnowledgeAnswer@1，冻结CHAT绑定，单个有界结构化生成，独立领域分类，标通用知识。只发送同会话通用知识历史与本人表达偏好，不包含本票资料；未知受理不盲重投。明确提示注入优先拒绝。翻译草稿缺语种时中文/英文续接同一草稿，其他缺项保留门禁。
- 对话草稿按本人+会话sessionStorage保存并防恢复竞态；待续答原回合各自订阅，缺号重取快照后重新订阅。消息缓存按真实查询键失效；终态Run关闭流，不显示错误恢复。任务卡容忍部分数组字段。

## 对话验收收尾方案（实施前登记）

针对 F01–F10/F24/F25/F33，补齐真实能力与引用标签组合：C09 返回启用版本的声明参数；Composer 在插入标签前用类型、枚举和必需项收集参数，发送时继续由 C04 校验并冻结。MCP 仅使用当前已批准的公开仓库参数，不把 `@` 单票材料拼入外发参数；ExtensionCall 必须带 conversation_id/parent_turn_id。

纯解释 Skill 的不可变说明、结果格式和用户参数进入新增 chat.general@2/chat.intent@2 的 reference_material 围栏；不修改既有版本、不进入系统提示词、不新增工具。纯解释 Skill 选择不被术语快路径吞掉，有单票引用时也只提供一般解释；已有字段答复仍用冻结证据。多选中只有一个实际动作能力，其他可为纯解释 Skill，多个实际动作明确拒绝以免静默丢弃。

结束会话持久化真实状态卡，无 Run 也有结束卡；未导出不宣称服务交付完成。新会话只显式携带 Case，不携带消息/摘要。C06 新会话显示本人当前已确认偏好数，有回合时显示该回合冻结值。验收用现有 Chrome/Playwright、项目 uv 环境，无安装；记录 MCP tools/call、纯解释 Skill 的冻结提示词与真实 CHAT、含糊意图真实样本、20轮与结束后新会话，随后停止源编辑交总控提交。

增量摘要补充方案：每次只读最近20个完整回合及最多20个待归档回合，用数据库 count 统计总轮数；已归档摘要按 covers_through_turn_no 增量推进。摘要限定最近明确的语言、货描范围、输出格式及有卡片佐证的未完事项，最多6条要求，最终按.env摘要token预算仅移除完整分号条目，不截断来源边界或安全限定句；不复制任意用户文本、单票编号/金额/日期/主体或模型猜测。摘要标历史要求，不能替代本次TaskSpec/字段证据；超出增量窗口注明更早明细未载入，不无界扫描或付费模型压缩。
