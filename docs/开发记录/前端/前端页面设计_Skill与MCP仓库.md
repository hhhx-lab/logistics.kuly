# 前端页面设计：Skill 与 MCP 仓库

版本：v0.1｜2026 年 9 月 28 日｜状态：前端目标设计；真实交付与未验范围见前端实施记录及后端逐条核验第12节

上位依据：[Skill 与 MCP 仓库产品设计](../../需求设计/Skill与MCP仓库_产品设计.md)第 1—7 节、[对话产品设计](../../需求设计/对话工作台与对话Agent_产品设计.md)第 4、10、11 节。共用视觉、状态与联动见[前端页面总规范](前端页面总规范与联动契约.md)。本页是轻量辅助能力管理，不建设应用商店。首版“创建 MCP”是为已有服务创建连接与授权记录，不是让用户在页面编写和托管 MCP 服务代码。

## 1. 页面骨架和控件清单

左导航“Skill / MCP”进入独立管理页。主区最大宽 1200 px，顶部标题“Skill 与 MCP”，副标题“为对话添加可选辅助能力”。右侧依次是描边“导入”、次要“新增 MCP 连接”、主按钮“新建 Skill”。按钮至少 40 px 命中区域，主要行为保持文字标签；不放“发布市场”“执行脚本”“创建 MCP 服务器”等未接通入口。

| 区域 | 顺序、位置、外观 | 操作 |
| --- | --- | --- |
| 顶部筛选行 | “全部／Skill／MCP”三段切换；名称与用途搜索；状态下拉“全部／可用／未启用／异常”；右端结果数 | 切换立即过滤本人有权条目；清除搜索恢复全列表。 |
| 条目列表 | 每行至少 64 px：类型图标、名称与一句用途、内置／自建／连接来源、版本或工具数、权限标签、状态、最近测试时间 | 点行主体开右侧详情板；行尾“启用／停用”和更多菜单。 |
| 详情侧板 | 桌面宽约 440 px，顶部名称、类型、版本、状态与关闭；中部能力说明／参数／授权；底部最近调用 | 详情不覆盖列表筛选和滚动；关板焦点回原行。 |
| 新建／导入层 | 由顶栏按钮开宽约 560 px 的表单面板，超过时全屏 | 顶部步骤、底部“保存草稿／验证／启用”按阶段出现；未保存退出提示保留或丢弃。 |
| 状态提示条 | 表单或详情顶部，浅蓝／黄／红底配文字 | 告知验证中、连接失败、权限不足和修复动作；最近测试成功须带时间。 |

条目排序默认“内置路由 → 可用自建 → 可用 MCP → 未启用／异常”，可选择按最近更新。列表行点击仅看详情，不立即调用能力；调用只发生在对话页中明确选中并发送、服务端再次鉴权后。只有内置条目而无自建能力时，正常显示内置列表，不在列表下方追加说明小字；整个列表无条目时仍显示“尚无自建能力”空态及创建入口。无搜索结果时显示已生效条件和“清除筛选”。加载中只用同位骨架屏，不展示假的“可用”数。

## 2. Skill 行、详情、创建和编辑

Skill 行左图标为文档／流程，名称下显示用途，右侧标“内置”或“我的”、当前启用版本、允许动作摘要与可用状态。内置“单据任务路由”可看说明和支持的 read_index／translate_review，但编辑、停用、删除键均不可出现；普通用户不得用同名自建条目覆盖它。自建 Skill 的状态分别为草稿灰、验证中蓝、可用绿、验证失败黄／红、已停用灰，文字完整显示，不能只用小色点。

| 控件／字段 | 表单位置与规则 | 点击结果 |
| --- | --- | --- |
| 新建 Skill | 顶栏主按钮 | 开空表单；默认“未启用草稿”，不因保存就进入 / 可用列表。 |
| 名称／唯一标识 | 表单首行两个输入；标识自动建议但可改 | 失焦检查本人作用域冲突；不能占用内置标识。 |
| 用途与适用条件 | 第二组：一句用途、何时使用、何时不使用 | 必填说明要写可执行范围；不能把“读全部用户单据”描述变成权限。 |
| 参数定义 | 可增删参数行：名称、类型、是否必填、说明、默认值 | “＋ 增加参数”加行；删行先确认未保存输入。校验 schema 和必填项。 |
| 允许的业务动作 | 白名单多选，按“只读／受控写入”分组 | 只显示当前可注册且有权限的动作；启动翻译仍必须经过内置路由和任务校验。 |
| 返回形式与步骤说明 | 文本／Markdown 编辑区，右侧只读预览 | 明示“任务说明，非系统提示词”；导入指令不覆盖系统规则。 |
| 保存草稿 | 表单底部次要按钮 | 保存当前内容和版本草稿，出现“待验证”；/ 仍不可选。 |
| 验证 | 保存后描边按钮 | 检查标识、schema、动作存在、说明长度与受限声明；错误就地指向字段。 |
| 启用 | 验证通过后主按钮 | 显示“对话中将看到的名称／版本／允许动作”确认层，确认后才进入 / 选择器。 |
| 编辑 | 自建详情右上 | 基于已启用版创建新版本草稿；旧版供历史消息审计，直到新版本启用前 / 仍显示旧启用版。 |
| 停用／重新启用 | 自建行尾开关＋文字 | 停用后新 / 候选消失，当前输入中已选标签变不可用；恢复必须通过有效验证。 |
| 删除／归档 | 自建详情更多菜单 | 先展示“停止新调用、列表隐藏、历史调用保留”，明确确认后归档；不能删除审计历史。 |

Skill 纯解释类可无业务动作，但详情须写“仅提供说明，不执行单证工作流”。涉及字段的 Skill 只可通过授权只读接口读取本票，不能因说明里出现“管理员”而获得提权。用户在对话明确选择 Skill 后，消息旁显示版本和实际调用状态；连接或权限变化发生在选中后、发送前时服务端仍拒绝旧标签调用。

## 3. 导入 Skill 的逐步动作

点顶栏“导入”先选“Skill 说明／manifest”或“MCP 连接描述”，不支持导入可执行包并运行。Skill 导入步骤：选择本地文本或粘贴说明 → 本地预览文件名／大小 → 服务端解析出名称、版本、参数与拟用业务动作 → 差异表逐项标“可用／未知动作／越权／不支持脚本” → 用户选择“保存为未启用草稿”。“启用”必须在验证和授权选择完成后单独点击。解析失败保留用户文件名与错误，允许重选，不把不可解析的包写成已安装。说明里命令式文字只作低信任任务材料；“忽略系统规则”在差异表红字标不可生效。导入层关闭时丢弃未保存解析临时内容，保留用户确认过的草稿。

## 4. MCP 连接行、详情与配置向导

MCP 行显示连接图标、显示名、受支持传输模板名称、端点安全摘要、已启用工具数、最近连接测试结果与时间。详情上半显示端点摘要和认证方式，不回显 Key；中部“已发现工具”表列工具名、用途、输入 schema 摘要、只读／写入／外发类别、当前授权和 schema 版本；底部“最近调用”列时间、调用者、Case（若有）、工具版本、结果／错误摘要，不显示原文全文或秘密参数。

| 步骤与控件 | 位置与动作 | 门禁／失败反馈 |
| --- | --- | --- |
| 新增 MCP 连接 | 顶栏次按钮 | 进入步骤 1“选择受支持连接模板”；不提供 shell 命令或任意传输输入框。 |
| 显示名／端点 | 步骤 2 表单顶部 | 校验受支持协议、主机与部署允许的网络目标；错误在字段下解释。 |
| 认证方式／凭证 | 步骤 2 下部，仅展示部署已支持方式 | 凭证只提交给服务端安全存储，输入框掩码；若个人凭证安全存储未准备好，整组输入禁用并解释，不收集明文。 |
| 保存连接草稿 | 底栏次按钮 | 建立未启用配置，不出现在 / 可用工具组。 |
| 测试连接 | 草稿详情与配置步骤 3 描边按钮 | 展示“握手 → 获取工具清单 → schema 校验”的真实过程、耗时和结果；失败显示鉴权、超时、端点不允许或协议不兼容的具体类别。 |
| 发现工具列表 | 测试成功后步骤 3 | 每工具复选框、权限类别、参数 schema、作用范围；默认未勾选写入／外发工具，首版仅能启用经评估的只读工具。 |
| 启用连接与工具 | 步骤 4 主按钮 | 确认显示已选工具、可读数据范围、服务目标；再次验证所有权与工具 schema 后才启用。 |
| 更新配置／重新测试 | 详情右上 | 配置变更后标“待测试”，受影响工具暂停新调用；旧调用记录仍指原版本。 |
| 停用／删除连接 | 行尾或详情更多 | 立即撤销新调用与 / 候选；删除需确认凭证后续处理和历史记录留存。 |

“测试成功”只说明测试时连接可达，状态旁必须有测试时间；每次真实调用仍重新检查连接、工具 schema、参数、用户权限和本票范围。schema 变更、认证失效或工具消失时，受影响工具标“待复核”，点击差异表查看旧／新 schema 并重新授权，不能沿用旧能力标签调用。对不支持的认证方式或传输，界面写明不能启用原因，不提供貌似可用的表单。

## 5. 与对话页的 / 联动及异常

管理页状态与对话 / 选择器由同一服务端注册表提供；启用后 / 按“内置 Skill／已启用 Skill／可用 MCP 工具”分组展示，停用或连接失败及时移除。对话选中后结构化标签包含 extension ID、版本和 tool ID；用户再选 @ 文件／快照时，先冻结有权 Case 和版本，再检查扩展能否读取这份范围。外部 MCP 回答标“外部工具返回”，不能直接变成本票已核验事实；如要回答本票字段，仍须查询带来源的业务视图并生成证据卡。扩展要求编辑字段、裁定 Issue 或导出时，界面引导到校验工作台的业务按钮与门禁，不让扩展直接改状态。

工具需要外发本票原文或敏感字段时，对话发送后、调用前先展示一次性授权卡：服务名称与目的地、拟发送的精确文件／字段／片段范围、用途，以及“取消调用／同意本次发送”。范围比用户选择的 @ 对象更大时必须缩小或重新选择；取消只停止该扩展调用，不撤销已上传原件或原问题。管理页的“启用工具”说明长期可用能力和权限上限，不代替某次实际数据外发的告知与许可；服务端再次按本次授权范围核验。

| 异常 | 列表／详情／对话表现 |
| --- | --- |
| Skill 验证失败 | 草稿保留，字段下说明错误；/ 不出现。 |
| MCP 连接失败或鉴权失败 | 行变黄／红并显示时间和错误类别；已插入对话标签变“不可用”，原问题仍在输入框。 |
| 工具 schema 变化 | 详情差异表、受影响工具“待复核”；拒绝旧标签调用。 |
| 无权访问目标 Case／快照 | 扩展调用被拒绝，不能靠提示词或历史缓存读取；不显示对方数据。 |
| 扩展返回诱导指令 | 内容作为外部资料显示；系统策略、业务字段和审核门禁不变。 |
| 用户删除扩展 | 新选择器无入口，旧消息仍可看其版本和调用状态，不重放。 |
| 外部 MCP 故障 | 只影响该辅助工具；内置上传、识别、翻译与导出 Run 状态继续由自己的事件源决定。 |

页面验收至少覆盖：自建 Skill 草稿、验证、预览、启用与版本更新；导入未知动作／脚本时不执行；真实 MCP 握手、schema 发现与只读调用；连接失败或 schema 变化阻止旧标签；/ 与 @ 同用时先鉴权后调用；停用后新候选消失、旧审计可查；用户不能编辑内置路由或系统提示词。

## 6. 可直接落版的轻量仓库与表单规格

1440 px 桌面以左导航 232 px、页面左右边距各 32 px 排布，仓库主体宽约 1144 px。标题行最小高 64 px，副标题在标题下而不挤入按钮组；右上三个入口固定顺序“导入 → 新增 MCP 连接 → 新建 Skill”。筛选行高 48 px、距标题 24 px，类型三段开关在左，搜索框宽 280 px，状态过滤紧随其后。条目列表距筛选 16 px，每行最小高 72 px、行间 8 px，普通行白底细边框圆角 12 px；状态色只出现在小胶囊和错误说明，不把整行染红。内置条目始终位于首组，分组标题可折叠但默认展开。

每个条目行从左到右固定为：40 px 类型图标 → 最少 280 px 名称／一句用途 → 120 px 来源与版本 → 最少 180 px 权限或工具数 → 144 px 状态／最近测试时间 → 120 px 启停与更多。行身点击只开详情，右侧开关只改变该条目的启用意图，两个目标不重叠；停用、归档和连接凭证删除使用明确对象的确认层。1440 px 下详情板从右侧滑入约 440 px，列表剩余宽不足以显示所有元数据时把次要列收入行详情，保持名称、状态和启停常显；详情与列表分别滚动，关闭后列表筛选和选中行不变。窗口不足 1024 px 时详情改全屏，顶栏“返回仓库”恢复原位置。

新建 Skill 与 MCP 配置都用宽约 560 px 的右侧向导层，顶端是当前步骤与保存状态，主体单列字段，底部固定“取消／保存草稿／下一步或启用”。标签放输入框上方，必填与权限说明紧邻字段；两列只用于 560 px 宽下简短的“名称／标识”和“参数类型／必填”，长用途、说明和 schema 始终占整行。步骤之间保留尚未提交的表单草稿，返回上一步不重新触发验证或连接测试；关闭未保存层先确认。Skill 预览左列展示最终在 `/ ` 中的名称、用途和版本，右列展示参数及允许动作；MCP 步骤 3 的工具列表逐工具显示 schema、只读／外发类别与授权开关，默认不勾选。验证失败在字段下写具体原因，焦点移动到首个错误，不仅给顶端红条。

“测试连接”显示真实的握手、发现、schema 校验三段状态与开始／结束时间；按钮在进行中禁重复请求，超时或失败保留草稿和已填安全配置，不回显凭证。启用成功后列表行和对话 `/ `候选读同一注册表，延迟刷新时显示“正在同步可用状态”而非先称可用；停用后已选对话标签按版本变不可用，但用户输入文本保留。此页只管理能力，不显示单证原文全文，也不提供可运行脚本的编辑器。

### 2026-10-03 能力组合边界补齐

G22 编辑器、服务端验证与执行器共用服务端返回的组合策略：至多四个只读步骤，或一个业务动作；不接受多业务及读写混合。编辑器即时解释不可执行组合，保存／验证／启用仍由服务端校验。

验收记录：`SKILL_ACTION_POLICY` 从注册动作表推导只读范围，服务端、动作目录、编辑器共用；定向回归验证4步只读允许、5步拒绝、单业务允许、多业务及读写混合拒绝。前端 `tsc -b` 通过。启用真实多步骤与执行器联调由对话模块统一完成，草稿操作未写入演示数据。

### 2026-10-10 五语界面与能力市场

- 设置页“界面语言”提供中文、English、Français、Español、Русский下拉列表；保存后切换静态页面文案和显示时间，用户名称、文件名、单证原文、译文和历史消息保留其原内容。界面语言独立于任务翻译语言，不默认为本次任务目标语。
- 翻译任务卡目标语言改为五语下拉列表；原件可为上述任意源语。预处理不能确认源语时沿用人工确认入口，不将法文和西班牙文按拉丁字符一律当成英语。五语支持覆盖对话路由、草稿、Run、人工源语确认、引用、预览、局部修订和DOCX/PDF导出。
- Skill/MCP 仓库、导入弹窗及新建 MCP 向导提供 DataClawHub 能力市场卡片，链接固定为 `https://dataclawhub.com/toolkits/skills`，新标签页打开。用户在站外自行注册登录、下载，再回来通过已有文本导入预览与启用流程加入当前 Agent。站外包或连接配置仍须满足本系统支持的能力契约，入口链接不代表自动执行下载包。
