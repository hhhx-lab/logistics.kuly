# 前端页面设计：单据管理台

2026-10-08 导出契约：交付物是当前确认版本的纯目标语言译本（所选 DOCX/PDF），可选各原件的识别稿 PDF；不生成复核报告。识别稿从冻结 ParseArtifact 的原文与布局生成，不冒充 MinerU 供应商原始 PDF。一个 Run 对应一个目标语言；其他语言使用各自 Run/确认/快照独立导出，当前不提供多语言一键批量翻译或导出。旧成功快照含报告只作接口兼容，不再展示报告下载；旧失败报告清单在原 Attempt 安全重试时升级为译本与识别稿，历史失败事件保留。

版本：v0.1｜2026 年 9 月 28 日｜状态：前端目标设计；真实交付与未验范围见前端实施记录及后端逐条核验第12节

上位依据：[单据管理台产品设计](../../需求设计/单据管理台_产品设计.md)第 1—11 节、[产品形态与需求规格](../../需求设计/物流单证智能识别与转换智能体_产品形态与需求规格.md)第 10 节、[校验产品设计](../../需求设计/单证翻译校验工作台与工作流_产品设计.md)第 3、8 节。共用尺寸、颜色、深链、事件与权限见[前端页面总规范](前端页面总规范与联动契约.md)。管理台是持久记录的入口；一行 Run 可含多份源文件，一个 Case 可含多次 Run，只有成功 Export Snapshot 的产物叫“转换后文件”。

## 1. 页面结构、导航和可折叠层级

页面从左导航“单据管理台”进入，主内容区最大宽 1440 px，外边距 32 px。顶栏、状态标签、筛选条、列表表头固定在主滚动区上方；批次列表滚动，右侧校验区打开时保留当前查询和行位置。窄屏表格缩为批次摘要卡，筛选折叠为抽屉，不能把关键状态或版本藏在仅悬停的控件里。

| 区域 | 位置与内容 | 点击／折叠 |
| --- | --- | --- |
| 标题栏 | 左：仅标题“单据管理台”；右：“刷新”“批量处理”“新建处理”按钮，不显示副标题、结果数或读取时间小字 | 新建处理去新对话和上传向导，不直接创建 Run。手动刷新读取持久快照后补事件；标签仍显示有权记录计数。 |
| 状态导航 | 标题下第一行：“已导出”“待复核与可导出”“处理中”“失败与取消”“识别与索引”“同票核对”“上传草稿”“全部” | 默认已导出；标签数只含有权记录。已导出、待复核／可导出和最近一次导出尝试失败可同时包含同一 Run；主行分别显示当前状态、历史交付与“上次导出失败”。 |
| 筛选工具条 | 搜索框、日期、来源地、收件人、处理人、类型、目标语言、“更多筛选”、版本范围和匹配范围 | 展开更多筛选不清除已选项；条件呈可删除标签；右端“重置筛选”。 |
| 列表表头 | 展开箭头、单票／Run、任务与语言、文件数／类型、处理人、时间、疑点、版本／状态、操作 | 点击表头排序只对支持字段生效，显示方向与排序依据；默认已导出按成功导出时间倒序。 |
| 批次行 | 一行一个 Run，显示主行实际使用的快照或当前工作版 | 点击行空白处仅展开／收起；点击 Case 名进单票概览；点击操作按钮才开复核、询问或下载。 |
| 批次展开区 | “参与原件”“疑点与处置”“交付文件”“快照历史”“任务时间线”可折叠分组 | 每份物理源文件一行；核对结论位于比较视图与处理记录，不生成报告文件行。 |
| 单票概览子视图 | 从 Case 标识进入，保留管理台外层筛选上下文 | 左上“返回列表”，中部原件目录、Run 时间线、当前业务版、问题与成功快照；关闭复核仍留概览。 |
| 右侧校验面板 | 默认收起，与对话页复用同一组件 | 开启时主列表次要列可折叠，筛选、展开、滚动和焦点恢复。 |

状态标签配文字与图标：已导出绿色只说明存在成功快照；当前工作版另显示“待复核／过期”。待复核黄色、失败红或黄按错误类型，识别索引蓝色且明确“无译文”。任何标签不可把 OCR 完成说成正式交付完成。

## 2. 批次行、文件行和每个动作

### 2.1 批次主行

主行第一行：Case 短号／名称、Run 短号、任务类型、目标语言、参与源文件数；第二行：实际展示的快照编号／成功导出时间，或未导出 Run 的最近活动时间；第三处紧凑徽标列显示当前状态、红黄疑点数量、当前工作版是否过期。处理人固定取 Run 发起人，并在旁标“发起人”，不从原件的发件人字段取值。已导出列表的地点、收件人、疑点和摘要来自主行所展示的冻结快照；当前工作版有新修订时，增加紫灰“历史交付；当前版待复核”带“查看当前版”入口，不能混写两版字段。

| 控件 | 位置／点击结果 | 状态约束 |
| --- | --- | --- |
| 左侧展开箭头／行空白 | 展开或收起该 Run 详情；箭头旋转，行底色改为页面浅灰 | 不把展开当作进入复核；键盘 Enter／Space 可操作。 |
| Case 名称 | 主行左上墨色文本，悬停转品牌橙并显示下划线 | 进入单票概览，保留返回列表时的筛选、展开和滚动。 |
| “查看本次” | 行右操作列 | 核对 Run 打开同票对比，其余打开校验工作台的 Run 总览；已导出行锁定主行实际展示快照，未导出行打开当前工作版。 |
| “向助手询问本次” | 行右更多菜单首项 | 新建会话并预置该行所示快照；未导出则预置 Run 和参与原件，不暗示交付。 |
| “查看交付” | 有成功快照的行右 | 展开交付文件分组并定位该快照；失败暂存不作为交付。 |
| “查看当前版” | 历史交付提示旁 | 只在用户显式点击后切换复核目标为当前工作版，旧行显示的快照不变。 |
| “重新处理” | 行右更多菜单 | 跳对话任务准备并预置 Case／选定文件；目标语言与范围需明示并按新 Task Spec 创建新 Run。 |
| “取消处理／请求取消” | 排队或运行中 Run 的更多菜单 | 与对话任务卡共用取消业务命令和幂等结果；确认层说明不删除原件与历史快照，外部请求状态不明时显示待核查而非直接写已取消。 |

### 2.2 参与原件与逻辑单据

每份参与的 DocumentVersion 占一个文件行：文件图标、原名、格式、大小／页数、document_version、上传人／时间、当前选定解析版、逻辑单据类型与页／区域、文件阶段与疑点数。文件名按钮打开原件；左箭头展开内部 LogicalDocument／DocumentSection 与“本次这张原件的摘要”。混合 PDF 仍是一份文件行，内部可有发票和箱单两条逻辑单据；正式目标语言译本仍按该物理文件对应一组。文件摘要默认最多三行，点击“展开摘要”显示任务目标、目标语言、关键字段概况、处理状态、所用业务／译文版与证据入口。摘要过期用紫灰“更新中”，不能用过期句子冒充当前事实。

| 文件行控件 | 动作 |
| --- | --- |
| “查看原件” | 已解析则传文件／解析／逻辑单据／区段与当前行版本；未解析只传 Case＋文件版本，打开只读预览。 |
| “询问这张单据” | 新建对话并固定该 DocumentVersion；若入口在已导出行，还固定主行实际展示的 Export Snapshot 及其中的解析版。两枚标签都在新会话可恢复；快照锁历史版本，原件标签将默认事实范围收窄到这张文件，明确同票比较才扩大到快照内其他原件。未导出行只固定原件与 Run 范围，不暗示已交付。 |
| 逻辑单据标签 | 展开该类型的区段、页／区域和字段来源；点击具体区段精准开复核，不跳文件首页。 |
| 摘要字段／疑点 | 有来源 ID 时打开校验工作台对应字段／Issue；缺可靠锚点时说明定位精度，不猜框。 |
| “目标语言 DOCX／PDF” | 仅成功快照产物显示；“预览”打开该快照只读输出，“下载”由 API 对每次读取重新鉴权并代理文件字节，支持断点 Range，不把对象存储直链交给浏览器。 |
| “复制文件信息” | 只复制当前有权查看的名称、版本和处理编号，不复制敏感原文或长期下载链接。 |

无正式译本的文件行显示“尚无正式译本”，不可放灰色假下载键。只读识别 Run 显示原件、解析结果及字段来源，译本和目标语言位置写“不适用／尚无译文”。部分上传失败的 Upload Session 在“上传草稿”区列成功／失败文件及重试入口，失败文件不计入处理原件数。

### 2.3 交付、历史与时间线

交付文件分组先按物理源文件排列其所选 DOCX／PDF，每份原件下可选识别稿 PDF；每个产物旁显示文件哈希短值、生成时间和来源映射。快照历史是可折叠列表，最新成功快照置顶，旧快照标“历史，只读”；点击旧快照后主行是否切换要由明确“查看该快照”动作完成，不能因悬停或展开自动换版本。历史筛选命中旧快照时，主行首先展示该命中快照，展开区另给“最新成功快照”入口。任务时间线按 RunEvent 序号显示上传、分类、解析、抽取、校验、翻译、复核、导出与失败；安全重试仍属于同一 Run，不插入伪造的新批次。收费外部请求待核查显示发生时间、请求键的受控摘要和操作权限；普通用户无“立即重试”。

## 3. 筛选栏逐控件语义

筛选条件之间是 AND，同一维度多选是 OR。搜索前先按身份和版本范围过滤，结果显示命中的具体文件、逻辑单据、字段角色与来源状态。所有可选列表只显示当前身份有权查看的人、Case 和数据。输入搜索后短暂防抖，再展示精确单票号／文件名建议，随后是摘要命中；摘要只帮助定位，不给“已核实事实”标签。

| 控件 | 默认值、弹层和动作 | 匹配口径／结果说明 |
| --- | --- | --- |
| 状态标签 | 默认“已导出”；单选标签 | 已导出按是否存在成功快照；其他标签按 Run 当前工作状态。标签可以重叠，不是互斥事实。 |
| 搜索框 | 占首行约 280 px，提示“搜索单票、文件、单号”；清除叉号 | 模糊文件名／Case 编号／已提取单号／短摘要；建议显示所属文件、版本与时间。自然语言解析出的条件先做可编辑标签。 |
| 日期类型 | 下拉默认“导出时间”；可选上传、处理发起、最近活动、复核 | 更换后日期区间按所选字段匹配，表头说明排序依据；UTC 存储按用户本地左闭右开日期换算。 |
| 日期区间 | 起止日期＋“近 7 天／近 30 天”，可清空 | 已导出默认导出时间倒序；切到其他时间时相应显示命中时刻。 |
| 来源地 | 第一层选择“起运地／承运人接货地／装货港／原产国地区”，默认起运地；第二层输入值 | 各角色独立，未提取不从发货人地址推断；结果注明角色、原文／规范值、所属区段。 |
| 收件人 | 角色下拉默认 Consignee，另有 Buyer、Notify Party；值输入 | 不同角色不混并；冲突候选可命中但显“待复核／多候选”，可开两处原文。 |
| 处理人 | 角色下拉默认 Run 发起人，另有复核人、导出确认人；授权用户选择框 | 显示实际匹配的角色与真实登录用户；不搜索单证正文人名。 |
| 单据类型／格式 | 多选发票、箱单、提单、其他及 PDF／图片／DOCX | 类型命中 LogicalDocument；同一混合 PDF 可同时有两类，格式命中物理源文件。 |
| 目标语言／风险状态 | 中文／英文及红项／黄项／无法判断多选 | 语言属于 Run／快照，不从 Case 上可覆盖字段读取；疑点来自同一目标版本。 |
| 版本范围 | 默认“仅当前结果”；已导出可切“包含历史快照” | 历史命中行展示实际命中快照；多快照命中取最近的命中者，仍一 Run 一行。 |
| 匹配范围 | 默认“同一逻辑单据”，显式可切“同一批次任意文件” | 默认单据条件须在同一 LogicalDocument，文件名／上传日期须属该源文件；放宽后逐条件列 A／B／C 命中来源。 |
| 仅已确认值 | 默认关，开关可用 | 关闭时识别候选可命中但标候选；开启只匹配已确认字段，不能只在视觉上过滤。 |
| 重置筛选 | 筛选条右端文字按钮 | 恢复默认状态、日期类型、匹配范围和版本范围；保留当前页签之外不保留旧查询。 |

搜索建议下方有“查看全部匹配”进入分页结果。表格采用游标分页或等价稳定分页，切页保留筛选和排序；新 RunEvent 到来时提示“有更新，刷新列表”，不在用户正看第 3 页时强行插入并打乱行位置。空结果分三种：“没有任何记录”给上传入口；“当前筛选无结果”展示生效标签与逐项清除；“索引更新中”允许元数据查询并标摘要暂不可用。不展示别人的记录数。

## 4. 单票概览子视图

点击 Case 标识进入同一管理台的单票概览，顶部显示 Case 名／短号、当前业务版、原件数、未决 Issue 数、最近活动和服务端给出的“保留至 YYYY-MM-DD HH:mm”；右端“在新对话询问”“重新处理”“更多”“返回列表”。“更多”内仅 Case 所有人可见“删除这票”，Run列表另提供明确标作“删除整票”的确认入口，与“取消处理”分隔显示；删除前列出整票影响范围。第一栏是原件目录，按 DocumentVersion 可展开解析历史与 LogicalDocument；第二栏按时间排列该票全部 Run（包括不同目标语言和只读识别）；第三栏是 Issue／人工裁定与成功 Export Snapshot。历史快照卡标原件／解析／业务／译文配对与时间，点“查看快照”进入只读复核，点“下载”取快照文件。当前工作版卡与历史卡分开，不能把新字段放到旧译本旁。原件在不同 Run 里仅以引用出现，不复制一份对象。

“在新对话询问”明确新建会话并预置 Case 当前版本标签，未选快照不自动选旧稿；从某快照卡点“询问这版”则固定该 Export Snapshot。“重新处理”预填 Case 与用户明确选中的原件，回对话要求摘要，不暗用上一轮目标语言。概览内若有多语言有效译本而只问“译成什么”，新会话后由 Agent 按规则澄清语言。返回列表恢复进入前状态。

“删除这票”先打开宽约 520 px 的确认层，不立即调用删除命令。层内固定列 Case 名／短号、原件版本数、Run 数、成功快照数、预计到期时间，并用红色文字写明“将删除本票全部历史记录与交付文件，无法恢复；不会删除其他单票”。下方说明“提交后立即不可访问；主存清理目标 24 小时内完成；加密备份最长 7 天后轮换删除；此前已下载或外发的副本无法由系统远程收回”，第三方服务另链接隐私文档中的已核实口径，不虚称本系统能立刻擦除对方数据。用户输入屏幕上显示的 Case 短号后，“确认删除这票”才可点；“返回”仅关闭层且焦点回“更多”。提交前以 M06 预览的 `case_version` 为准，提交中禁双击；若版本变化，保留确认层、清空输入并刷新数量，要求重新核对。收到 `202` 后立即离开单票概览，清该 Case 的 Query 缓存、输入标签和侧栏内容，返回列表原位置并显示不含票据内容的清理状态卡；清理失败只给“联系管理员／稍后查看状态”，绝不恢复旧资料。到期自动删除走同一可见结果；页面本地倒计时只是提示，最终以服务端鉴权和期限为准。

## 5. 跨页面动作、保存位置和错误

| 动作 | 联动结果 |
| --- | --- |
| 主行“查看本次” | 打开校验面板，已导出锁主行展示快照；未导出锁当前工作版。 |
| 文件名／摘要来源／Issue | 传稳定 ID 与版本，先鉴权后按源锚点定位；关闭恢复本行与滚动。 |
| 正式译本“预览／下载” | 只读当前所选 Export Snapshot 产物；下载重新鉴权，失败只重试下载。 |
| “向助手询问本次” | 新会话，不携旧会话摘要；历史筛选行固定命中快照，未导出固定 Run。 |
| 对话“查看管理记录” | 按 Case＋Run／快照 ID 定位，必要时展开行并显式标识所选版本。 |
| 校验中保存修订／导出 | 同一业务事件刷新受影响行和摘要状态；列表正在看历史快照时不改那份旧字段。 |

## 6. 可直接落版的列表与检索规格

1440 px 桌面且左导航展开时，管理台主区可用宽约 1208 px；左右各 32 px 页面边距后，表格按 1144 px 基准排布。标题行高约 64 px，状态页签 44 px，筛选工具区至少 88 px，表头 44 px 并在主列表滚动时固定。筛选第二行只在有条件标签或“更多筛选”打开时出现，避免默认把列表挤到屏幕下方。批次行最小高 72 px，第一行放 Case／Run、任务和主要状态，第二行放时间与版本；展开后的物理文件行最小高 56 px、内部 LogicalDocument 行最小高 44 px。行的展开箭头与“查看本次”按钮分别有 40 × 40 px 点击范围，操作列常显而不只在悬停时出现。

搜索建议浮层与搜索框同宽、最多先显示 8 条，建议行包含命中字段、所属 Case／文件、时间与候选／已确认状态。建议输入短暂防抖时保留上一结果并标“正在更新”，新结果按查询版本替换；不能让旧建议在新查询下面短暂冒充新命中。条件标签位于筛选行下方，每个标签有独立删除键；切换日期类型会保留用户选的日期值但立即用新口径重新查询，并在标签中写明“按上传／导出／复核时间”。历史范围打开后，主行必须显示实际命中的快照编号与时间，打开复核和向助手询问都沿用该编号。

空列表分“从未处理”“当前筛选无结果”“摘要索引更新中”三种：前两种分别给“新建处理”和“清除筛选”，第三种仍展示可由元数据查到的记录，不做全页空态。导出文件按物理源文件分卡排列，每卡先原件版、再对应成功 DOCX／PDF，所选识别稿 PDF 在末尾独占一卡；下载按钮旁显示格式与大小，失败暂存文件永不占该位置。
