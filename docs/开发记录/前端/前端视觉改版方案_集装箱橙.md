# 前端视觉改版方案：集装箱橙

本文记录五个页面从首版视觉切换到「集装箱橙」风格的目标、令牌、图标与 Logo 规则、逐页细节和验收方式。功能、路由、数据契约和交互流程不在本次范围内，任何改动都不得删减需求文档规定的功能入口。配色候选与对比样例见 [视觉改版配色探索](assets/视觉改版配色探索.html)（第 1 套）。

## 1. 目标与范围

- **目标**：在不改变信息结构的前提下，让界面更简约、更有质感：中性冷灰为底，墨色承担文字和主要层次，国际橙只出现在主操作、品牌和当前位置上。
- **范围**：全局颜色令牌、按钮／输入／卡片／标签等基础组件、图标集、Logo 与 favicon、五个页面及登录页的视觉细节。
- **不在范围**：页面布局与断点规则（仍以《前端页面总规范与联动契约》第 2 节为准）、深色主题、组件行为与接口。

## 2. 颜色令牌

对比度按 WCAG AA 计算：正文与小字至少 4.5:1，图标和边框等非文字元素至少 3:1。

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| page / card / nav | #F3F4F6 / #FFFFFF / #FFFFFF | 页面底、卡片、左导航；导航用 1 px 分隔线与内容区分开 |
| ink / ink-2 / ink-3 | #111418 / #4A525C / #636B75 | 主文字、次文字、弱提示；ink-3 在 page 上 4.9:1 |
| ink-4 | #8B929C | 只用于未选中图标与装饰，不承载文字 |
| line / line-strong | #E4E7EB / #D2D7DD | 常规分隔线；悬停与输入框悬停边框 |
| fill / fill-strong | #F1F2F4 / #E8EAEE | 中性悬停底；会话列表、文件树等列表内的「当前项」 |
| brand | #CF460F | 主按钮底色（白字 4.6:1）、开关开启态、页签下划线、焦点环 |
| brand-hover / brand-press | #B83C0B / #A0340A | 主按钮悬停、按下 |
| brand-ink | #B23A0A | 橙色文字与链接（白底 6.0:1，brand-soft 底 5.4:1） |
| brand-vivid | #FF5A1F | 只用于 Logo 底块、进度条等非文字强调 |
| brand-soft / brand-line | #FFF1EA / #F8C9B3 | 左导航当前页、引用类标签、提示条的浅底与边框 |
| sel / sel-soft / sel-line | #1F63D6 / #EDF3FE / #A9C4F2 | 校验工作台中原件、译段、字段的「当前选中」，与红黄绿语义分开 |
| risk | #A52727，浅底 #FFF1F0，框 #D14646 | 不变 |
| warn | #8A5700，浅底 #FFF8E1，框 #D99A24 | 浅底调黄，与 brand-soft 拉开 |
| ok / hist / dis | 沿用首版 | 不变 |

使用规则：

- 橙色保持稀缺：主按钮、左导航当前页图标、Logo、进度、开关、页签下划线、文字链接。表格里的单号、案件名等主信息用墨色，悬停才转橙并显示下划线。
- **选项选中态用墨色**：标签式选项选中为墨底白字；卡片式选项选中为墨色 2 px 内描边。这样橙色不会和风险红、警告黄的浅底混淆。
- 校验工作台里的原件高亮、译段与字段联动沿用蓝色「选中」语义（sel），满足总规范 2.1「蓝＝当前选中」。
- 焦点环用 brand 色，2 px 外环。

## 3. 形状、阴影与动效

- 圆角沿用：卡片 12 px，按钮与输入 8 px，状态胶囊全圆角。
- 卡片：1 px line 边框加极浅阴影 `0 1px 2px rgba(17,20,24,.04)`；可点卡片悬停时边框转 line-strong，阴影加深到 `0 4px 12px rgba(17,20,24,.06)`，不位移。
- 主按钮带 1 px 顶部内高光和浅橙投影；次按钮带 1 px 浅投影；输入框聚焦时边框转 brand，外加 3 px 浅橙光晕。
- 弹层与右侧面板阴影 `0 12px 32px rgba(17,20,24,.12)`，加 1 px 边线。
- 不使用大面积渐变；只有 Logo 底块用轻微的同色渐变。

## 4. 图标

- 图标集换成 Lucide 1.53（ISC 协议）的路径数据，写在 `src/components/Icon.tsx`。组件接口 `<Icon name size strokeWidth>` 不变，不新增依赖。
- 尺寸档位：12（状态胶囊内）、14（紧凑行内与小按钮）、16（常规按钮与列表）、18（左导航）、20 及以上（空状态与品牌）。
- 描边按显示尺寸补偿：12 px 时线宽约 1.25 px，16 px 约 1.4 px，18 px 及以上 1.5 px，避免小图标发虚、大图标显粗。`strokeWidth` 参数按相对粗细处理，默认 1.5。
- 未选中的导航与工具图标用 ink-4 或 ink-3，悬停转 ink；状态图标始终与文字成对出现。
- 「对话工作台」导航改用独立的对话图标，不再复用 Logo。

## 5. Logo「以单为帆」

- 图形：一张右上角折起的单据作船帆，下面是船头朝右的船身，底部两道浪线，表达单据随货漂洋过海、一路被校验护送。
- 实现：`Icon name="logo"` 输出实心图形，单据上的两行文字用遮罩镂空，因此放在任何底色上都能透出底色；品牌底块统一用 `.brand-tile`（brand-vivid 同色渐变＋顶部内高光）。
- 使用位置：左导航与会话侧栏顶部、登录页、助手消息头像、favicon。
- favicon 为 32 px 圆角橙色底块配白色图形。

## 6. 逐页细节清单

| 区域 | 细节 |
| --- | --- |
| 左导航（应用外壳、会话侧栏） | 白底加右侧分隔线；当前页为 brand-soft 底、墨色文字、brand 图标；悬停为 fill 底；头像改为墨底白字 |
| 登录页 | Logo 底块、标题层级、输入框聚焦光晕、主按钮 |
| 对话工作台 | 用户气泡改为中性浅底；引用标签用 brand-soft；输入框圆角与聚焦光晕；发送按钮 brand；候选浮层当前项为 fill |
| 单证校验工作台 | 文件树当前项为 fill-strong；字段与译段选中为 sel-soft；原件选中框为 sel；页签当前项为墨色文字加 brand 下划线；原件画布底色与卡片区分 |
| 单据管理台 | 页签、筛选标签选中为墨底白字；案件名为墨色，悬停转橙；展开行用 page 浅底 |
| Skill 与 MCP 仓库 | 列表卡选中为墨色内描边；开关开启为 brand；向导步骤当前项为 brand 数字底 |
| 设置与我的记忆 | 分类筛选与选项卡片选中为墨色；记忆建议区为 brand-soft 浅底 |

## 7. 验收

1. `npm run typecheck` 与 `npm run build` 通过。
2. 本地前后端启动后，用无头 Chrome 在 1440×900 和 1280 px 宽度下逐页截图：登录、对话、校验工作台、单据管理台、整票详情、Skill/MCP、设置、我的记忆，核对第 6 节每一项。
3. 抽查对比度：主按钮白字、brand-ink 链接、ink-3 弱提示、导航当前项图标。
4. 独立检查：对照本文和总规范，确认功能入口一个不少、状态仍以「图标＋文字」成对出现、红黄绿蓝语义没有被橙色替代。
5. 完成后在《前端实施记录_五个页面的落地与验证》补充验证结果，并更新总规范 2.1、2.2 的令牌与图标说明。
