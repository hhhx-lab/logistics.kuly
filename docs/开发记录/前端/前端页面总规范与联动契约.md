# 前端页面总规范与联动契约

2026-10-08 导出契约：交付物是当前确认版本的纯目标语言译本（所选 DOCX/PDF），可选各原件的识别稿 PDF；不生成复核报告。识别稿从冻结 ParseArtifact 的原文与布局生成，不冒充 MinerU 供应商原始 PDF。一个 Run 对应一个目标语言；其他语言使用各自 Run/确认/快照独立导出，当前不提供多语言一键批量翻译或导出。旧成功快照含报告只作接口兼容，不再展示报告下载；旧失败报告清单在原 Attempt 安全重试时升级为译本与识别稿，历史失败事件保留。

版本：v0.1｜2026 年 9 月 28 日｜状态：前端目标设计；真实交付与未验范围见前端实施记录及后端逐条核验第12节

## 2. 视觉基线与可度量尺寸

以 1440 × 900 的桌面浏览器内容区为设计基准，采用 8 px 间距网格。数值是首版前端实现起点；若可用阅读宽度不足，以本节的最小宽度和断点行为优先，不通过压缩文字、字段或三栏来凑尺寸。

| 项目 | 基线 | 行为 |
| --- | --- | --- |
| 应用左导航 | 展开 232 px；折叠 64 px | 顶部显示品牌／折叠键，中部为导航和最近会话，底部为头像与设置。折叠只隐藏文字，不丢失功能入口和焦点。 |
| 主内容区 | 对话阅读列最多 760 px；管理台内容最多 1440 px | 对话居中；管理台使用更宽的表格区。内容区最小可读宽度 560 px。 |
| 右侧校验面板 | 来源快速定位初次 620 px；完整双语复核初次至少 832 px；可拖 520–900 px | 实际最大值还须保证主内容至少 560 px；完整复核无法容纳 832 px 时直接展开为全屏对照。用户宽度偏好按身份保存，不改变 Case 数据。 |
| 顶栏与底栏 | 普通顶栏 56 px；对话输入区按内容增高，上限约 240 px | 长文输入在框内滚动，不把消息流挤到不可读。 |
| 控件高度 | 常规按钮／输入 36 px；紧凑标签 28 px；主要操作 40 px | 命中区域至少 40 × 40 px；密集表格里的图标按钮仍有可触达面积。 |
| 内容间距 | 页面外边距 32 px、卡片内边距 16–20 px、列表行高至少 52 px | 窄屏外边距 16 px，长文件名截断并保留完整名称提示。 |
| 布局切换 | 快速定位：主区 560 px＋复核区 520 px 无法共存时全屏；完整复核：复核区可用外宽不足 832 px 时全屏 | 默认 1440 px 桌面上的完整复核为全屏双栏，来源快速定位仍可用紧凑侧板；不把三栏塞入窄侧板。全屏返回时恢复原页面位置。 |

两种打开意图共用一套校验工作台状态：点击 Run 的“查看并校验／查看本次”、复核待办或导出前检查，属于**完整复核**，默认必须看得清原文与译文；点击单张来源卡或文件原件，属于**快速定位**，可先用窄侧板。计算宽度时，主区保留至少 560 px，主区与面板之间及外侧总计保留 48 px；先按当前导航宽度尝试，不足再将左导航临时折叠为 64 px。完整复核面板的 832 px 外宽扣除两侧各 24 px 内边距后，至少留下 784 px 给双栏工作区；仍不足则从右展开同一工作台的全屏形态。以 1440 px 浏览器宽度为例，快速定位可在临时折叠导航后使用 620 px 侧板，完整复核直接全屏；导航已折叠时约从 1504 px 起能开完整复核侧板，导航展开时约从 1672 px 起能同时保留展开导航。临时折叠不覆盖用户保存的导航偏好，关闭后恢复。

用户保存的面板宽度用于快速定位；完整复核暂用 `max(832 px, 用户偏好宽度)`，再受可用空间与 900 px 上限约束。若结果小于 832 px，改为全屏，而不把缩小后的宽度当作可读双栏。用户进入后主动拖窄时可转单栏标签视图，并始终保留“展开双语对照”入口；这一临时宽度不自动改写用户在设置页保存的偏好。

全局字体优先系统中文无衬线；正文 14 px／行高 1.55，辅助说明 12–13 px，表格 13 px，页面标题 24 px，卡片标题 16 px。编号、金额与时间使用等宽数字或等宽字形，确保相邻行可比较；金额、件数不得只凭颜色区分。源文、译文正文可在阅读区调至 14–18 px，调字号不改变来源锚点。

配色整体称为「集装箱橙」，令牌来源与取舍见《前端视觉改版方案_集装箱橙》。橙色只用于主操作、品牌与当前位置，不表达任何业务状态。原件高亮优先用半透明边框而不是遮蔽文字：红＝当前定位的高风险来源，黄＝待确认，蓝＝当前选中，绿＝已确认。长期显示的普通字段不画满屏彩框。蓝色选中框可以与红色风险标识同时存在，此时外层蓝轮廓、角标红色风险；不能因为选中而消掉风险。所有状态含文本和图标，符合暗色模式或系统高对比度时仍保持同一语义；首版先实现浅色主题，不用未设计的深色主题宣称已交付。

### 2.2 形状、层级与屏幕验收基线

页面不使用大面积渐变、悬浮装饰或满屏卡片阴影。普通卡片圆角 12 px、输入与按钮圆角 8 px、状态胶囊为全圆角；普通卡用 1 px 分隔线加 `0 1px 2px rgba(17,20,24,.04)` 的极浅阴影，弹层和右侧面板可用 `0 12px 32px rgba(17,20,24,.12)` 的浅阴影。图标统一用 Lucide 线性图标，尺寸取 12／14／16／18／20 px 五档并按尺寸补偿描边；品牌标志为「以单为帆」，规则见《前端视觉改版方案_集装箱橙》第 4、5 节。标准内容间距按 8／16／24／32 px 四档取值；同一组标签间 8 px、相关控件间 16 px、独立区块间 24 px，一级页面边距 32 px。悬停只改变底色或边框，不移动按钮位置；按下态用更深主色，键盘焦点显示 2 px 外环。危险确认层的红色用于影响说明和最终确认按钮，普通“取消”保持中性。

固定层的覆盖顺序为页面内容 → 固定顶／底栏 → 候选弹层 → 右侧校验区 → 模态确认层 → 非遮挡状态通知。菜单或候选属于某个侧板／模态时，其 portal 层级高于该宿主一层，保证侧板内菜单可点击；底层页面的弹层不能盖住上层服务界面。同一时刻只允许一个模态层获得焦点；通知不遮住底部“发送”或“导出”。文件预览、字段表、消息列各自滚动，固定栏加实色背景和下边线，不能让正文透过造成难读。任何长文件名、客户名、单号至少保留一处可查看完整文本的位置，省略号不得遮掉版本和风险状态。

视觉验收要在 1440×900 和 1920×1080 两种桌面窗口至少逐页查看空白、处理中、红黄疑点、历史只读和成功导出状态；在 1280 px 宽窗口核对导航折叠与管理台卡片列，在 1024 px 窗口核对全屏校验。1440 px 的完整复核打开时必须同时看见清晰的原文和译文，纵向至少留 540 px 给阅读内容；若固定栏或浏览器缩放使内容低于此值，折叠次要摘要或使次要栏进入抽屉，不截断正文。当前文档规定视觉基线，最终“好不好看、读起来累不累”仍须基于可交互原型截图与真实三文件样本复核，不能只凭令牌表宣称验证完成。

## 3. 统一操作、滚动与折叠规则

1. 页面切换只改变视图。Run、上传和导出由服务端任务持续执行；关闭面板、刷新和离开页面都不取消业务任务。
2. 任一可点击行的“展开”和“打开原件”是不同目标。展开控件为左侧箭头，打开动作使用明确文字按钮；整行点击的默认行为必须在页面文档写清楚。
3. 折叠区保留展开状态：左导航按用户偏好；管理台筛选／批次按当前页面会话；复核文件树、字段组按用户＋Case；长消息按消息 ID。换身份后不能沿用前一用户的本地状态。
4. 侧板展开／收起动画 160–220 ms，滚动定位不超过 240 ms；先完成容器布局和目标渲染，再滚动锚点至视区中部。新定位或用户手动滚动立即取消旧动画。系统设置减少动态效果时直接切换。
5. 面板宽度可拖拽，也必须有键盘可用的“缩小／放大”控件；每次键盘动作以 32 px 调整，尺寸立即在前端生效，释放后保存偏好。双击拖拽柄恢复 620 px 基线。尺寸变化不重跑 OCR、清空表单或丢选中字段。
6. 页面各阅读区独立滚动。用户向上阅读旧消息或原文时，SSE 新事件只更新状态徽标和“有新进度”入口，不抢滚动。用户主动点“回到最新”才回底部；新来源定位是一次显式例外。
7. 所有弹层的 Esc 只关闭最上层，未保存表单先询问丢弃或保留草稿；关闭后焦点返回触发按钮。复核区、选择器、对话框不能同时争夺键盘焦点。
8. 危险操作采用明确对象、影响范围、操作者与版本的确认层；禁用按钮旁提供“还缺什么”，不能让用户猜测。

## 4. 页面间唯一联动契约

| 来源 → 目标 | 触发 | 传递和冻结 | 目标动作／返回 |
| --- | --- | --- | --- |
| 对话 → 校验 | 任务卡、证据卡、疑点卡、“在原件中查看” | Case、Run（如有）、原件版本；有解析时加 parse artifact、逻辑单据／区段／锚点；有译文时加语言、业务／译文版、预览版；疑点加 Issue | 先鉴权和版本核对，再展开面板、选文件、定位。关闭返回原消息及输入草稿。 |
| 管理台 → 校验 | 批次、文件、疑点、正式译本或所选识别稿 PDF 入口 | 已导出行传该行实际展示的 Export Snapshot；未导出行传当前工作版；未解析文件仅传 Case＋原件版本 | 历史只读，显式切当前；关闭保留筛选、展开、滚动和焦点。 |
| 管理台 → 对话 | “向助手询问本次／这张原件” | 新会话预置结构化 Case／Run／文件或快照标签；历史筛选行预置所显示快照 | 不携带旧会话消息或摘要；发送时按标签语义冻结版本。 |
| 对话 → 管理台 | “查看管理记录”／文件卡 | Case 与 Run ID，必要时成功快照 ID | 定位到相应列表行或单票概览，不用文件名猜记录。 |
| 仓库 → 对话 | 启用／停用 Skill、MCP 工具或连接状态改变 | 扩展 ID、版本、授权状态 | 斜杠选择器刷新；已插入后失效的标签变“不可用”，阻止调用并保留输入文字。 |
| 设置 → 对话 | 确认、编辑或删除我的记忆 | 当前用户的偏好版本 | 仅之后的新回合重新装配；已经完成的回答和 Task Spec 不回写。 |
| 校验 → 对话／管理台 | 修订、裁定、确认、导出 | 同一业务事件中的版本、Issue、RunEvent、Export Snapshot | 当前卡与列表刷新；旧消息／旧快照维持原版本并标注历史。 |

深链只包含受控 ID、版本和视图位置，不放原件路径、长期下载 URL、密钥、原文全文或提示词。显式点击携带的目标版本优先于“上次打开位置”；保存的上次位置只在没有显式目标时恢复。所有深链与下载都由服务端按当前身份重新鉴权。切换身份、权限撤销、来源删除时清理该身份的缓存并在原位置显示无权／不可用，不能拿旧缓存继续预览。

### 4.1 需求到页面的逐项对照

下表的章节均指本文件开头链接的原有产品需求文档；“对话”“校验”“管理”“扩展”“设置”对应本目录五份前端页面设计。实现验收时按行核对，不以某页已有相似按钮替代另一页要求的版本或状态语义。

| 编号 | 原需求定位 | 前端落点与必须兑现的动作 |

## 5. 通用状态与数据展示的真值

| 状态 | 呈现 | 用户可做什么 |
| --- | --- | --- |
| 首次加载 | 原地骨架屏，保留区域高度 | 可返回；不显示假的零记录或假进度。 |
| 空数据 | 写明是没有记录、没有匹配项还是尚未解析 | 新建处理、清除筛选或等待真实任务。 |
| 连接恢复 | 显示最后持久状态和时间、“正在恢复连接” | 查看已有内容；不可把连接中断写成处理完成。 |
| 数据过期／版本冲突 | 历史／过期标记及“重新加载差异” | 查看旧版只读，显式切换当前或重提修订。 |
| 权限不足 | 受限占位，不显示被拒绝记录的字段、摘要或数量 | 返回有权页面；不可用缓存兜底。 |
| 外部请求待核查 | 黄／红状态卡、请求时间、Run 状态；普通用户仅可查看 | 有核查权限者才见核查入口，不能普通重试。 |
| 导出中／失败 | 显示真实文件级回检状态；失败暂存不进入正式文件 | 安全重试失败步骤；旧成功快照仍可下载。 |

上传进度只根据 Upload Session 的真实字节或文件完成数；Run 进度只根据持久化 RunEvent。模型抽取、翻译、规则判定无可靠分母时只显示阶段文字。各页先取快照再订阅事件，按操作内递增 seq 去重并用 Last-Event-ID 补齐；列表与卡片不得各自推测一个状态。摘要用于定位，不作为事实证据。日期由 UTC 存储换算为用户时区，首版默认中国标准时间；文件名、身份与客户字段只在授权后显示。

## 6. 可访问性与验收门槛

所有按钮有可见文本或无歧义读屏名称，Tab 顺序跟视觉阅读顺序一致。Enter 激活按钮，Space 激活开关／复选项，Esc 关闭顶层弹层；打开校验面板后焦点进入标题或目标问题，关闭后回原按钮。表格排序、风险、确认、历史只读均有文字说明；不使用仅靠悬停才能发现的核心操作。表单错误定位到字段并以文字说明修复方式；状态变化用适度的实时播报，不把每个流式 token 都读出。指向原文的红黄框不可遮住原文。不得因动画破坏焦点或让滚动把用户正在输入的内容移走。

前端验收以需求文档中的真实场景为准，至少逐条走通：新上传与只读问答、翻译澄清、多文件任务、双向来源定位、两类版本修订、确认后整组导出、历史快照、管理台组合搜索、斜杠扩展和用户记忆隔离。页面规格不代替后端权限与版本检查；本文描述目标交互；当前工程已接真实前后端，实际完成及未验范围以《前端实施记录_五个页面的落地与验证》和后端逐条核验第12节为准，不由目标设计推导全部验收通过。

## 7. 跨页面联调路径与视觉签收

下表直接对应五份需求文档的首版业务路径。前端实现时每条都要用同一票真实或获授权样本走通，不能只在某个组件故事页用静态假数据展示状态。

| 路径 | 起点与终点 | 必须观察到的联动 |
| --- | --- | --- |
| 上传后澄清翻译 | 对话主卡／拖入 → 文件托盘 → 要求摘要 → 翻译 Run | 两入口同流；上传、归票、语言分开；缺项不建翻译 Run。 |
| 只问文件内容 | 上传原件 → read_index → 原文证据卡 → 校验快速定位 | 不要求目标语言，不出现译文或导出；引用固定原件与解析版。 |
| 问题复核与修订 | 对话疑点 → 校验完整复核 → 字段或译段修订 → 返回任务卡 | 业务／译文版各自递增，受影响预览过期；旧回答不被重写，关闭回原消息和草稿。 |
| 整组交付 | 校验清单 → ReviewConfirmation → 导出 → 管理台 | 逐源文件译本与所选识别稿 PDF 全成功才形成 Export Snapshot；暂存产物不进正式列表。 |
| 历史追问 | 管理台历史筛选行 → 只读校验／新会话询问 | 传该行实际命中的快照，旧字段不混当前版；返回恢复筛选、展开和滚动。 |
| 扩展调用 | 对话 `/ `＋`@ ` → 范围鉴权 → 必要时外发授权 → Skill/MCP 结果 | 扩展版、工具版、票据版均固定；外部资料不覆盖系统策略或单票事实。 |
| 会话与身份隔离 | 结束服务／切换用户 → 新对话 | 新会话只装系统策略与本人已确认偏好；旧会话摘要、其他用户候选及缓存不得带入。 |

功能布局可以据此开发，但文字方案不能替代视觉样机。至少在 1440×900、1920×1080 和较窄窗口检查五页的空态、处理中、红黄疑点、历史只读和成功导出：长文件名是否可读，来源框是否遮文字，双栏是否仍能判断数字和日期，滑入／关闭是否跳滚动，键盘焦点是否回到原控件。若样机显示 832 px 面板仍难以判读原件局部，应改用全屏对照，不继续缩小两张整页 PDF。OCR 效果、小规则包和导出回检要用业务样本另行验收，前端不得把未覆盖或未验证显示成通过。
