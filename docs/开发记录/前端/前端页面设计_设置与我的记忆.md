## 1. 入口、布局和信息边界

左导航底部的本人头像／姓名点击后打开菜单：“设置”“我的记忆”。“设置”进入同一页面的“界面偏好”段，“我的记忆”直接定位记忆段；左侧二级导航宽约 200 px，右侧表单／列表阅读宽 680–800 px。窄屏二级导航变顶部标签，不将记忆管理塞进狭窄弹窗。顶端显示“设置”标题、当前用户显示名及已有的上次保存时间，不显示其他用户数量或任何客户单据字段。

| 区域 | 默认内容 | 动作和不得包含的内容 |
| --- | --- | --- |
| 顶栏 | 标题、当前用户身份、上次保存时间 | 身份从登录态读取，用户切换后重新加载；不展示系统密钥。 |
| 二级导航 | “界面偏好”“我的记忆”“会话与数据说明” | 切换同页区块，保留各自未保存草稿；离开时按未保存规则处理。 |
| 界面偏好 | 时区、说明语言、复核面板宽度和减少动态效果 | 影响显示及阅读，不改历史 Run 的目标语言或导出结果。 |
| 我的记忆 | 已确认偏好列表、待确认建议、添加按钮 | 仅保存本人可复用的偏好，不存本票金额、收件人、地址、原件全文、密钥或旧会话摘要。 |
| 会话与数据说明 | 系统策略、会话摘要、Case 事实与用户记忆的边界文字 | 只读解释；不提供“编辑系统提示词”“导入旧聊天作为记忆”按钮。 |

## 2. 界面偏好的逐控件行为

| 控件 | 位置／默认 | 保存和影响 |
| --- | --- | --- |
| 界面说明语言 | 首行单选／下拉；默认中文 | 改页面辅助文案和将来 Agent 回答偏好；本轮明确用户要求优先。不能自动推断翻译目标语言。 |
| 时区 | 第二行搜索式下拉，首版默认中国标准时间 | 列表、事件和导出时间按该时区显示；数据库 UTC 不变。日期筛选使用所选本地日的左闭右开区间。 |
| 复核面板宽度 | 滑块 520–900 px、数值显示、“恢复默认 620 px”按钮 | 此偏好控制来源快速定位侧板；完整复核临时至少取 832 px，不够则全屏，不改写保存值。拖动只预览布局，保存后作为该用户偏好；实际宽度仍受中央最小 560 px 限制。拖动不改来源定位或重新 OCR，键盘左右键每次 32 px。 |
| 减少动态效果 | 开关，默认跟随系统；可选“跟随系统／始终减少／使用标准过渡” | 影响面板展开和滚动动画；减少时直接定位，不减少状态文字。 |
| 保存界面设置 | 区块底部主按钮；无修改时禁用 | 保存成功展示时间；失败保留草稿并给重试。不会更改当前任务内容或历史快照。 |
| 取消修改 | 保存键左侧文字按钮 | 恢复最近已保存的本用户界面偏好；未保存退出先明确提示。 |

界面偏好存在浏览器本地与服务端同步时以当前登录用户记录为准；切换身份立即清除前一身份的本地宽度、时区和候选缓存。时区变更后管理台日期控件应提示“时间显示已改为……，筛选区间已重新计算”，不悄悄保留按旧时区解释的查询。面板宽度在不满足主区可读宽度时暂用全屏，不覆盖用户保存的偏好宽度。

## 3. “我的记忆”列表、建议和编辑

列表顶部左侧只显示标题“我的记忆”，右侧“＋ 添加偏好”；标题下不显示副文案或账户整体记忆版本。列表每行白卡，包含类别、偏好内容、状态“已确认”、创建方式“我手动添加／我确认的建议”、更新时间、版本和行尾“编辑／删除”。不展示 Case 业务数值作为记忆候选。按最近更新排序，可按类别筛选；无记忆时写“尚未保存长期偏好，新的会话仍可正常使用”，不给自动回填历史聊天按钮。

| 类别 | 表单允许的内容 | 使用边界 |
| --- | --- | --- |
| 回答语言与术语解释 | 例如“解释物流术语时优先用简体中文” | 只影响表达，不能把英文目标语言任务改为中文。 |
| 常用目标语言 | 例如“常用英文译本” | 对未说明目标语言的翻译只显示一键建议，用户当次点击确认后才可启动 Run。 |
| 输出呈现 | 例如偏好先看风险清单或常用 DOCX＋PDF 展示方式 | 不自动跳过复核、改任务格式或改变已冻结 Task Spec。 |
| 获确认术语偏好 | 个人常用称呼及说明 | 只是个人偏好；若与领域事实、审核术语或当轮明确要求冲突，不覆盖后者。团队标准须另走发布流程。 |

| 控件／步骤 | 用户看见和操作什么 | 服务端与跨页效果 |
| --- | --- | --- |
| 对话建议“记住这个偏好？” | Agent 只在用户明确要求或多次重复后给一张待确认建议卡，展示拟保存的准确文字、类别和“确认保存／这次不保存” | 点击确认才写当前用户记忆；没有点击不能自动长期保存。当前任务一句“这次翻成英文”不可自动变成记忆。 |
| 待确认建议区 | 列表上方品牌橙浅底边框，逐条显示来源“来自本次明确请求／重复设置建议”与建议时间 | “确认”转为已确认列表，“忽略”仅移除建议；未确认建议不进入新会话上下文。 |
| 添加偏好 | 列表右上主按钮 | 打开表单：类别、内容、可选适用条件；底部“取消／预览影响／保存并确认”。 |
| 预览影响 | 表单底部描边按钮 | 展示“未来新回合可能采用什么表达”“不会改变当前 Run、旧对话、旧快照”，不预执行模型任务。 |
| 保存并确认 | 表单主按钮 | 再展示完整内容、当前用户与影响范围；确认后写版本、来源与时间。敏感单据值或密钥样式被拒绝并指出字段。 |
| 编辑 | 行尾文字按钮 | 基于旧版打开表单；保存后形成新偏好版本，之后的新回合生效；旧回答不被重写。 |
| 删除 | 行尾危险文字按钮，不用红色填充主按钮 | 确认层写明“今后的回合不再读取；已完成任务和审计按保留规则处理”；确认后从有效记忆移除。 |
| 查看来源 | 卡片下方细字／展开箭头 | 展示用户确认时间、来源类型和版本；若源会话已无权限，显示受限说明而非泄露原文。 |

表单保存禁用条件必须可见：内容为空、过长、含明显密钥或某票金额／客户地址等业务事实、类别不匹配、权限失效。用户坚持“记住这票收件人是某公司”时，引导“到单据管理台查看或在新会话 @ 该票”，不保存为长期用户记忆。用户可以编辑自己的偏好，不可编辑系统提示词、工具白名单或审核规则；页面不提供绕过服务端校验的“高级模式”。

## 4. 会话与数据说明

本段是三张只读信息卡，可折叠但默认展开标题与一句摘要：

1. “系统策略”：项目维护，版本化，用于领域边界、权限、防注入和证据要求；普通用户不可编辑，外部 Skill/MCP/文件内容也不能覆盖。
2. “我的长期偏好”：仅本人确认的设置；新会话和后续旧会话回合可按当前用户身份加载；当前明确任务要求优先于偏好。
3. “单票与会话记忆”：Case、文件、Run、快照事实带版本留在业务存储；只有当前上传或显式 @ 时按权限装配。本会话最多保留近 20 轮和只属于该会话的旧轮次摘要；结束后的新会话不加载旧聊天或摘要。

每卡“了解如何关联历史单据”进入对话页面并在输入区提示 @ 选择；“查看单据管理台”进入管理台。两个入口不自动绑定任何历史票据，也不把卡内说明写成新的用户记忆。系统策略卡不暴露完整系统提示词或内部密钥。

## 5. 联动、权限、错误与验收

记忆保存、编辑、删除成功后，页面更新当前用户记忆版本；对话下一条**新回合**重新读取已确认偏好，不在正在生成的同一回合中途切换，也不回写旧消息。后台 Run 的 Task Spec、目标语言、所选输出格式、已导出的文件均不因设置更改而变化。用户从管理台“向助手询问”新建会话时也只加载系统策略＋当前用户偏好＋显式关联的单票业务记忆，不带旧会话摘要。删除记忆影响未来上下文，但历史审计按既定保留策略留痕且不向其他用户开放。

| 情形 | 页面反馈 |
| --- | --- |
| 保存时网络断开 | 保留本地未保存草稿，显示失败与“重试保存”；不把待保存内容标为已确认。 |
| 多端同时修改 | 显示服务端当前版本与本地草稿差异，提供复制草稿或重新加载，不能静默覆盖。 |
| 用户切换／退出 | 清理前一用户列表、建议、缓存和输入草稿；新身份重新鉴权读取。 |
| 想保存单票事实或秘密 | 字段下解释“这属于单票业务资料／敏感凭证”，阻止保存并给管理台或配置流程入口。 |
| 已确认偏好与当轮要求冲突 | 对话按当轮要求执行；设置仍保留但不强制应用。 |
| 偏好目标语言但本次未明确 | 对话给出可点击建议并询问，不能据此直接创建翻译 Run。 |
| 没有任何记忆 | 空状态清楚说明不影响对话，不引导从旧会话自动导入。 |

验收至少覆盖：对话明确提出记忆建议后未确认不保存；确认后新会话可读取表达偏好但不加载旧聊天；常用目标语言只成为建议而非默认翻译指令；删除后后续回合不再装配；另一用户不可见本人的记忆与候选；切时区后管理台日期命中与显示一致；拖动复核宽度并刷新后恢复偏好但窄屏仍全屏；系统提示词不可编辑。

## 6. 可直接落版的设置与记忆列表规格

1440 px 桌面左导航展开 232 px，页面左右各留 32 px；页标题、本人显示名及已有的上次保存时间在顶部 64 px 区域。二级导航宽 200 px，与右侧内容间隔 32 px；右侧设置内容宽 680–800 px，不拉满剩余屏幕。二级导航选中项用主文字和 3 px 品牌橙左边条，未选项只用中性色，不借绿／红暗示业务状态。各设置区块上下间距 24 px，卡片白底细框、圆角 12 px、内边距 20 px；字段标签在控件上方 8 px，辅助文案在控件下方 8 px，错误文案紧随对应字段。

“界面偏好”每行先左侧 180 px 字段名与一句说明，再右侧实际控件；时区下拉和界面语言选择宽约 320 px。面板宽度滑块的滑轨宽至少 280 px，右端显示当前 px 数值，滑轨下标出 520、620、900 三个刻度；拖动时即时预览快速定位侧板宽度，松开后仍需按“保存界面设置”才写入账户偏好。滑块的 32 px 键盘步进与侧板拖拽柄一致。底部保存／取消按钮始终在表单结束处，不固定遮挡说明文字；未保存草稿离开页面出现对象明确的确认层。

“我的记忆”顶部左侧显示标题，右侧 40 px 高“＋ 添加偏好”，标题下不设边界说明或账户整体版本行；待确认建议在已确认列表之前，以品牌橙浅底框和“尚未保存”文字区分。记忆行最小高 88 px，左侧类别与偏好内容，右侧状态、更新时间、编辑和删除；内容超过两行时用“展开内容”读取全文，不能截断适用条件后使偏好含义改变。编辑表单宽不超过 560 px，类别先选、内容后填，底部“预览影响／保存并确认”并列；确认层清楚显示将写入的完整文字和当前用户。删除用危险文字按钮，不和整行点击混用。列表为空时给新增入口但不推荐自动导入旧聊天。

“会话与数据说明”三张只读卡默认仅展开标题和一句摘要，点展开箭头才显示完整边界与跳转按钮；展开状态只保留在当前用户的页面会话。窗口不足 900 px 时二级导航变顶部标签，设置表单改单列，记忆行的操作下移为一行可见文字按钮；不能因窄屏把“删除”“系统策略只读”等关键状态藏到悬停菜单。身份切换时先清除旧卡片和草稿，再读取新用户资料，加载期间以骨架占位而非旧内容过渡。
